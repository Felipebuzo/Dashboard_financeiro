*  FinTrack — Dashboard de Finanças Pessoais

Aplicação web para controle de finanças pessoais, desenvolvida com React e TypeScript.

## Demo

[Acesse o projeto ao vivo](https://dashboard-financeiro-blue-psi.vercel.app/)

##  Funcionalidades

- Cadastro de receitas e despesas
- Dashboard com resumo financeiro (saldo, receitas e despesas)
- Gráfico de gastos por categoria
- Cotação do dólar em tempo real (AwesomeAPI)
- Dados persistidos no localStorage
- Layout responsivo para mobile e desktop

##  Tecnologias

- React
- TypeScript
- Tailwind CSS
- Vite
- AwesomeAPI

##  Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/Felipebuzo/Dashboard_financeiro.git

# Entre na pasta
cd Dashboard_financeiro

# Instale as dependências
npm install

# Rode o projeto
npm run dev
```
